# iEnc

맥에서 영상을 구간 지정해 빠르게 인코딩하는 앱입니다. (만드는 중 — 지금은 구간 고르기까지, 인코딩은 아직)

지금 되는 것:

- 영상을 창에 끌어 놓거나 **영상 불러오기** 로 열면 FFmpeg 로 직접 풀어 미리보기합니다. QuickTime 이 못 여는 MKV · AVI · WMV · FLV · RM · VOB · TS 등도 확장 설치 없이 열립니다.
- **구간 고르기**: 미리보기 아래 필름 띠의 노란 테두리 양쪽 손잡이를 끌어 시작·끝을 정합니다. 시작 시각은 시작점 위, 끝 시각은 끝점 아래에 나오고 −[10|1|0.1] · [0.1|1|10]+ 초 단추로 세밀하게 맞춥니다. 띠를 누르거나 끌면 그 자리를 보여 줍니다.
- **구간 자르기 (⌘K)**: 지금 구간을 아래 타임라인 끝에 넣습니다. 영상은 그대로 남아 또 자를 수 있고, 다른 영상의 구간도 섞어 쌓을 수 있습니다.
- **타임라인**: 자른 구간을 순서대로 붙여 영상 한 줄(구간의 필름 띠) + 소리 한 줄(파형)로 보여 줍니다. 구간 폭은 길이에 비례하고 확대·축소(핀치 · ⌘+ · ⌘− · 전체 보기 ⌘0)됩니다.
  - 구간을 누르면 노란 테두리가 생기고 위 재생바에 그 원본과 구간이 열립니다. 범위를 바꾸면 **구간 적용**(그 구간 고치기) 또는 **새 구간으로 자르기**.
  - 영상 줄을 끌어 순서를 바꾸고, Delete 키나 오른쪽 클릭으로 지웁니다.
  - 소리 줄의 흰 선을 위아래로 끌면 그 구간 음량(−30 ~ +12 dB)이 바뀝니다. 오른쪽 클릭: 0 dB · ±6 dB · 소리 끄기. (변환할 때 적용 — 변환은 아직)
  - 맨 끝 **영상 추가** 는 빈 화면으로 돌아가 새 영상을 엽니다. 구간을 고르지 않은 상태(새 영상·빈 화면)면 파랗게 강조됩니다.
- **프레임 단위로 정확한 탐색**: 직전 키프레임부터 목표 프레임까지 풀어 보여 줍니다. 한 프레임 앞뒤(←/→)는 방금 푼 프레임을 다시 써서 바로 넘어갑니다.

| 키 | 하는 일 |
|---|---|
| 스페이스 | 구간 재생·멈춤 (구간 밖이면 시작점부터, 끝점에서 멈춤) |
| ← / → | 한 프레임 뒤·앞 |
| J / L | 5초 뒤·앞 |
| I / O | 지금 자리를 구간 시작·끝으로 |
| ⌘K | 구간 자르기 |
- 미리보기 옆에 영상 정보 (기본 폭 320, 경계를 끌어 240~520. 창 크기를 바꾸면 미리보기만 줄고 늚): 컨테이너 · 스트림별 코덱 · 프로파일 · 픽셀 형식 · 해상도 · 화소 비율 · 프레임률 · 인터레이스 · 색 공간 · 회전 · 키프레임 간격 · 색인 유무, 그리고 미리보기 진단(디코더 · 탐색 시간 · 오류). **복사** 로 글로 가져갈 수 있습니다. AVI 처럼 태그가 옛 윈도우 인코딩(한국어 CP949 · 일본어 Shift-JIS · 중국어)으로 들어 있으면 알아서 골라 풉니다.
- 디코딩은 기본이 소프트웨어(탐색이 더 빠름), AV1 만 VideoToolbox. 설정(⌘,)에서 "하드웨어 디코딩" 을 켜면 VideoToolbox 를 씁니다.
- 오른쪽 사이드바 **인코딩 설정** (도구 막대 단추로 여닫음, 본문을 줄임): 영상(코덱 HEVC·H.264·원본 그대로, 품질/비트레이트, 해상도 — 원본·원본 중 가장 큰/작은 것·2160~480p, 비율이 다를 때 검은 여백/꽉 채우기, 프레임률, 10비트, 디인터레이스) · 소리(AAC·원본·없음, 비트레이트, 채널, 소리 크기 고르게) · 출력(MP4·MKV·MOV, 구간마다/한 파일로, 자막·제목 태그) + **영상 변환하기**. 지금은 설정 화면만 있고 변환은 아직 안 됩니다.
- 설정(⌘,): 기본 저장 위치(원본과 같은 폴더 / 정한 폴더 / 매번 묻기), 파일 이름 규칙(`{이름}` `{번호}` `{시작}` `{날짜}` 칸, 기본 `{이름}_iEnc_{번호}`), 하드웨어 디코딩.
- 자른 구간 목록은 아직 저장되지 않습니다 (앱을 닫으면 사라짐).

## 요구 사항

- macOS 26 이상, Apple 실리콘

## 빌드

```sh
Scripts/build-ffmpeg.sh   # FFmpeg 8.0 공유 라이브러리(LGPL)를 Vendor/ffmpeg 에 (처음 한 번)
open iEnc.xcodeproj
```
