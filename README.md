# iEnc

맥에서 영상을 구간 지정해 빠르게 인코딩하는 앱입니다. (만드는 중)

지금 되는 것:

- 영상을 창에 끌어 놓거나 **영상 불러오기** 로 열면 FFmpeg 로 직접 풀어 미리보기합니다. QuickTime 이 못 여는 MKV · AVI · WMV · FLV · RM · VOB · TS 등도 확장 설치 없이 열립니다.
- **구간 고르기**: 미리보기 아래 필름 띠의 노란 테두리 양쪽 손잡이를 끌어 시작·끝을 정합니다. 시작 시각은 시작점 위, 끝 시각은 끝점 아래에 나오고 −[10|1|0.1] · [0.1|1|10]+ 초 단추로 세밀하게 맞춥니다. 띠를 누르거나 끌면 그 자리를 보여 줍니다.
- 구간 자르기 줄 왼쪽에 지금 재생 위치와 |← →| 단추(아이콘만, 툴팁으로 설명)(지금 자리를 구간 시작·끝으로, I·O 키와 같음).
- **구간 자르기 (⌘K)**: 지금 구간을 아래 타임라인 끝에 넣습니다. 영상은 그대로 남아 또 자를 수 있고, 다른 영상의 구간도 섞어 쌓을 수 있습니다.
- **소리 트랙** (구간 자르기 옆 🔊 단추, 소리가 있는 영상만): 소리 트랙이 여럿이면 미리보기로 **들을 트랙**(하나)을 고르고, 자를 구간에 **넣을 트랙**을 체크(모두 · 몇 개 · 없음)합니다. 타임라인 구간의 소리 줄에 넣을 트랙(eng·jpn 등)이 표시되고, 소리를 뺀 구간은 흐리게 보입니다. 타임라인 구간을 오른쪽 클릭 › 소리 트랙 으로도 바로 바꿉니다. 변환하면 고른 트랙이 그만큼 들어가고(첫 트랙이 기본), 한 파일로 합칠 때 트랙 수가 모자란 구간은 그 자리를 무음으로 채웁니다.
- **왼쪽 사이드바 (불러온 영상)**: 한 번이라도 연 영상이 썸네일 · 길이 · 자른 구간 수와 함께 쌓입니다. 누르면 구간 없이(전체 범위) 그 영상이 열리고, 지금 위에 열린 영상은 노란 테두리입니다. 오른쪽 클릭으로 목록에서 뺄 수 있습니다(타임라인에 그 영상 구간이 있으면 못 뺌). 맨 아래 **영상 추가**(⌘O)로 바로 파일을 고릅니다. 여러 개를 한 번에 고르거나 끌어 놓으면 모두 목록에 들어가고 첫 영상이 열립니다 (나머지는 길이·썸네일·파형만 미리 만듦).
- **타임라인**: 자른 구간을 순서대로 붙여 시간 눈금자(이어 붙인 결과의 시각) + 영상 한 줄(구간의 필름 띠) + 소리 한 줄(파형: 연한 색 = 순간 최댓값, 진한 색 = 평균 세기)로 보여 줍니다. 파형은 영상을 처음 열 때 영상 전체를 한 번만 만들고, 구간은 그 일부를 잘라 그립니다. 소리가 파일 전체에 섞여 있어 NAS 의 큰 파일은 수십 초 걸리고 그동안 왼쪽부터 차오릅니다. 구간 폭은 길이에 비례하고 확대·축소(핀치 · ⌘+ · ⌘− · 전체 보기 ⌘0)됩니다.
  - 구간을 누르면 노란 테두리가 생기고 위 재생바에 그 원본과 구간이 열립니다. 범위를 바꾸면 **구간 적용**(그 구간 고치기) 또는 **새 구간으로 자르기**.
  - 영상 줄을 끌어 다른 구간의 왼쪽 반에 놓으면 그 앞, 오른쪽 반이면 그 뒤로 옮겨집니다. Delete 키나 오른쪽 클릭으로 지웁니다.
  - 소리 줄의 흰 선을 위아래로 끌면 그 구간 음량(−30 ~ +12 dB)이 바뀝니다. 오른쪽 클릭: 0 dB · ±6 dB · 소리 끄기. (변환할 때 적용 — 변환은 아직)
- **프레임 단위로 정확한 탐색**: 직전 키프레임부터 목표 프레임까지 풀어 보여 줍니다. 한 프레임 앞뒤(←/→)는 방금 푼 프레임을 다시 써서 바로 넘어갑니다.

| 키 | 하는 일 |
|---|---|
| 스페이스 | 구간 재생·멈춤 (구간 밖이면 시작점부터, 끝점에서 멈춤) |
| ← / → | 한 프레임 뒤·앞 |
| J / L | 5초 뒤·앞 |
| I / O | 지금 자리를 구간 시작·끝으로 |
| ⌘K | 구간 자르기 |
- 미리보기 옆에 영상 정보 (제목 막대 ⓘ 로 보이기·숨기기) (기본 폭 320, 경계를 끌어 240~520. 창 크기를 바꾸면 미리보기만 줄고 늚): 컨테이너 · 스트림별 코덱 · 프로파일 · 픽셀 형식 · 해상도 · 화소 비율 · 프레임률 · 인터레이스 · 색 공간 · 회전 · 키프레임 간격 · 색인 유무, 그리고 미리보기 진단(디코더 · 탐색 시간 · 오류). **복사** 로 글로 가져갈 수 있습니다. AVI 처럼 태그가 옛 윈도우 인코딩(한국어 CP949 · 일본어 Shift-JIS · 중국어)으로 들어 있으면 알아서 골라 풉니다.
- 디코딩은 기본이 소프트웨어(탐색이 더 빠름), AV1 만 VideoToolbox. 설정(⌘,)에서 "하드웨어 디코딩" 을 켜면 VideoToolbox 를 씁니다.
- **영상 변환하기**: 앱 안의 ffmpeg 실행 파일로 압축합니다.
  - **하드웨어** (HEVC·H.264, VideoToolbox): 미디어 엔진이 해서 CPU 를 거의 안 쓰고 빠름 (720p 실시간 약 17배). 같은 화질이면 파일이 큼. 동시에 여러 개 돌려도 전체 속도는 같음(엔진 하나).
  - **CPU** (HEVC·x265, H.264·x264, macOS 27 이상): 성능 코어를 다 써서 같은 화질을 더 작게. "압축 수고"(빠르게·보통·작게)와 화질(CRF)을 고름. x265 보통은 하드웨어보다 4배쯤 느리지만 같은 화질에서 약 20~40% 작음.
  - 구간마다 파일 하나: 구간마다 정확한 프레임부터 잘라 압축. 한 파일로: 구간마다 크기·화소 비율·회전·프레임률을 맞춰 이어 붙임(화면 비율은 첫 구간을 따름, 비율이 다르면 검은 여백 또는 꽉 채우기).
  - 타임라인에서 맞춘 구간 음량(dB)과 "소리 크기 고르게"(loudnorm)가 적용됩니다. 소리 "원본 그대로"면 음량은 못 바꿉니다.
  - 변환 중 **효율 코어로만**(켜고 끌 수 있음 — 다른 앱이 안 느려지는 대신 변환 15~20배 느려짐)과 **잠시 멈춤**.
  - 변환 전 **예상 크기**(비트레이트 지정·원본 그대로는 계산, 품질 기준은 짧은 조각 몇 개를 시험 인코딩해 어림), 변환 중 진행률(소수 한 자리)·남은 시간 · 지난/예상 시간 · 지금/예상 크기 · 속도, **취소**(만들던 파일은 지움), 끝나면 Finder 에서 보기.
  - 원본 그대로(다시 압축 안 함)는 시작점이 키프레임에 맞춰져 조금 앞당겨질 수 있고, 한 파일로 합치기는 같은 형식 영상끼리만 됩니다.
- 오른쪽 사이드바 **인코딩 설정** (도구 막대 단추로 여닫음, 본문을 줄임): 영상(코덱 HEVC·H.264·원본 그대로, 품질/비트레이트, 해상도 — 원본·원본 중 가장 큰/작은 것·2160~480p, 비율이 다를 때 검은 여백/꽉 채우기, 프레임률, 10비트, 디인터레이스) · 소리(AAC·원본·없음, 비트레이트, 채널, 소리 크기 고르게) · 출력(MP4·MKV·MOV, 구간마다/한 파일로, 자막·제목 태그) + **영상 변환하기**. 지금은 설정 화면만 있고 변환은 아직 안 됩니다.
- 설정(⌘,): CPU 사용량(최대·절반·4분의 1 — 영상 풀기·필터·x264·x265 스레드 수. 하드웨어 압축엔 거의 상관없음), 기본 저장 위치(원본과 같은 폴더 / 정한 폴더 / 매번 묻기), 파일 이름 규칙(`{이름}` `{번호}` `{시작}` `{날짜}` 칸, 기본 `{이름}_iEnc_{번호}`), 하드웨어 디코딩.
- 불러온 영상 목록과 자른 구간은 저장하지 않습니다 (앱을 닫으면 사라짐, 일부러). **파일 › 새 프로젝트 (⌘N)** 로 모두 비우고 처음부터 시작합니다. 인코딩 설정은 그대로 남습니다.
- 창: 왼쪽 사이드바 210 · 인코딩 사이드바 310 은 폭 고정, 본문은 최소 500 까지 줄어듭니다.

## 요구 사항

- macOS 26 이상, Apple 실리콘

## 빌드

```sh
Scripts/build-ffmpeg.sh       # FFmpeg 8.0 공유 라이브러리 + ffmpeg 실행 파일(LGPL)을 Vendor/ffmpeg 에 (처음 한 번)
brew install x264 x265
Scripts/build-ffmpeg-gpl.sh   # x264·x265 가 든 ffmpeg-gpl (GPL, 정적) 을 Vendor/ffmpeg-gpl 에 (없으면 하드웨어 인코딩만)
open iEnc.xcodeproj
```

## 라이선스

MIT. 앱에 들어가는 FFmpeg 라이브러리와 ffmpeg 실행 파일은 LGPL 2.1 이상입니다 (GPL·nonfree 구성 요소 없이 빌드, `Scripts/build-ffmpeg.sh`). ffmpeg 실행 파일은 앱과 따로 실행됩니다.
x264·x265 가 든 `ffmpeg-gpl` 실행 파일(`Scripts/build-ffmpeg-gpl.sh`, Homebrew 의 x264·x265 정적 라이브러리로 정적 빌드)은 GPL 2 이상입니다. 앱 코드와 링크하지 않고 따로 실행하므로 앱은 MIT 로 남습니다. 배포할 때는 FFmpeg·x264·x265 소스를 함께 제공해야 합니다.
