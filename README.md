# iEnc

맥에서 영상을 구간 지정해 빠르게 인코딩하는 앱입니다. (만드는 중 — 지금은 **미리보기 검증판**)

지금 되는 것:

- 영상을 창에 끌어 놓으면 FFmpeg 로 직접 풀어 미리보기합니다. QuickTime 이 못 여는 MKV · AVI · WMV · FLV · RM · VOB · TS 등도 확장 설치 없이 열립니다.
- **프레임 단위로 정확한 탐색**: 직전 키프레임부터 목표 프레임까지 풀어 보여 줍니다. 한 프레임 앞뒤(←/→)는 방금 푼 프레임을 다시 써서 바로 넘어갑니다.
- 재생 (스페이스), 5초 앞뒤 (J/L)
- 오른쪽 칸에 영상 정보: 컨테이너 · 스트림별 코덱 · 프로파일 · 픽셀 형식 · 해상도 · 화소 비율 · 프레임률 · 인터레이스 · 색 공간 · 회전 · 키프레임 간격 · 색인 유무, 그리고 미리보기 진단(디코더 · 탐색 시간 · 오류). **복사** 로 글로 가져갈 수 있습니다.
- 디코딩은 기본이 소프트웨어(탐색이 더 빠름), AV1 만 VideoToolbox. "하드웨어 디코딩" 을 켜면 VideoToolbox 를 씁니다.

## 요구 사항

- macOS 26 이상, Apple 실리콘

## 빌드

```sh
Scripts/build-ffmpeg.sh   # FFmpeg 8.0 공유 라이브러리(LGPL)를 Vendor/ffmpeg 에 (처음 한 번)
open iEnc.xcodeproj
```
